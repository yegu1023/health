# 식단 기록
개인용 모바일 우선 식단 기록 웹. 빌드나 설치 없이 실행하는 HTML/CSS/JavaScript 프로젝트입니다.

## 실행
프로젝트 폴더에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000 접속.

## GitHub Pages
저장소에 index.html, style.css, app.js를 업로드하고 Settings → Pages에서 main 브랜치의 /(root)를 선택합니다. 저장소 공개 여부와 Pages 사용 가능 여부는 계정 설정에 따라 확인해야 합니다. 이 프로젝트는 배포를 자동으로 수행하지 않습니다.

## 기능
- 식품 등록·수정, 기본 식단과 사용자 템플릿, 어제 식단 복사
- 끼니별 섭취량 자동 계산, 칼로리·탄단지 목표와 잔여량, 열량 기준 비율
- 물 빠른 입력·직접 입력·취소
- 일별 완료 상태, 달력, 주·월 통계
- g 직접 설정 / 비율 / 단백질 고정 방식 목표 계산, 목표 적용일
- JSON 백업 내보내기·가져오기 (가져오기는 기존 데이터 교체)

## 데이터와 주의점
데이터는 현재 브라우저의 localStorage에 저장됩니다. 자동 기기 동기화·서버 DB·로그인은 없습니다. 브라우저 데이터를 삭제하거나 다른 주소로 접속하면 기존 기록을 볼 수 없으므로 정기 백업을 권장합니다. 식단 기록 자체를 GitHub에 업로드하지 마세요.
초기 식품 영양값과 목표는 참고용이며 제품 성분표/개인 설정으로 수정하세요. 식품 변경은 과거 식사에 소급 적용되지 않습니다. 물은 별도 기록이며 음식에 포함된 전체 수분량을 계산하지 않습니다.
통계 평균은 식단 완료일만, 물 평균은 물 입력일만 포함합니다. 기간 목표선은 기간 마지막 날 목표입니다. 영양표 칼로리와 탄단지 열량 합계는 표기 방식 때문에 다를 수 있습니다.

## 테스트
`node --check app.js`. 브라우저에서 입력, 새로고침 유지, 날짜 이동, 목표 계산, 백업을 확인합니다.

## v3 패치

- 음식 추가 → 공공 식품 DB 검색 → 이름/제조사 검색 → 선택 → 섭취량 확인 → 저장.
- 식약처 342,920건, 농촌진흥청 1,858건, 해양수산부 1,814건을 통합했습니다. 중복 식품코드 1건을 제거해 346,591건입니다.
- 원본 출처: 공공데이터포털에서 제공하는 각 기관 통합식품영양성분정보 CSV. 데이터 기준일: 식약처 2026-09-29, 농촌진흥청 2025-12-23, 해양수산부 2025-01-13.
- 100g/100ml 기준을 유지하며, 빈 영양값은 사용자가 보완해야 저장할 수 있습니다. 선택 시 내 식품에도 등록됩니다.
- 최초 검색 시 약 10.6MB의 압축 데이터를 내려받아 Worker에서 검색합니다. 최신 Chrome, Edge, Safari 등 DecompressionStream 지원 브라우저가 필요합니다. 메모리에는 전체 DB가 올라가며, 브라우저 HTTP 캐시 정책에 따라 재다운로드될 수 있습니다.
- 관리 → 내 식품 → 삭제. 과거 기록과 고정 식단의 저장된 영양값은 유지됩니다.
- 기존 localStorage 키를 그대로 사용합니다. 같은 사이트 주소·같은 브라우저를 사용하면 기존 기록이 유지됩니다. 업데이트 전 JSON 백업을 권장합니다.
- Supabase는 아직 연결되지 않았습니다. 현재 저장은 기기/브라우저별이며 자동 동기화되지 않습니다.
