# v17.1 · 운동 화면 개선

압축 안 nutrition-tracker 폴더의 파일을 GitHub의 같은 폴더에 덮어쓰세요.
기존 data 폴더는 그대로 둡니다. Supabase 설정 변경이나 SQL 실행은 없습니다.
배포 완료 후 새로고침하세요. 개인 기록이나 백업 가져오기는 필요하지 않습니다.

- 휴식 카드의 흰 버튼 글자색과 모바일 버튼 배치 수정.
- 운동 카드에 완료 본세트의 중량 × 반복 횟수 표시. 같은 기록은 50kg × 12회 · 3세트처럼 묶고, 다른 기록은 순서대로 표시.
- 운동 통계의 시작일·종료일과 기간 조회, 최근 7일/이번 달/최근 28일 추가. 빠른 기간은 실제 오늘 기준.
- 운동 입력 맨 아래에 선택 날짜의 오늘 운동 요약 추가: 수행 종목 수, 완료 본세트, 총 반복 횟수, 운동시간, 총 운동량, 부위별·종목별 기록.
- 기간 통계에서 종목별 수행 변화 중복 영역 제거. 기존 종목별 히스토리는 유지.
- 선택 메뉴·주요 버튼·체크·포커스 색상을 파란색으로 변경.

완료한 본세트만 집계하며 준비 세트는 제외합니다. 총 운동량은 입력 중량 × 반복 횟수의 합계입니다.
기간 운동시간은 본세트 완료 기록이 있는 날짜의 저장된 운동시간입니다.
기존 식단·운동·사진·계정·동기화 데이터 형식은 변경하지 않습니다.

검증: v17.1 요약·기간·원본 불변 테스트, v17 음식 검색/저장, v16 동기화 및 휴식 알림 회귀 테스트 통과.
실제 휴대폰의 시각 검사 및 운영 서버 시험은 수행하지 못했습니다.
