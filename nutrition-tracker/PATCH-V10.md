2. 압축 안 nutrition-tracker 폴더의 app.js, shared.js, batch.js, photos.js, workout.js, index.html, style.css 7개 파일을 GitHub의 기존 nutrition-tracker 폴더에 덮어쓰세요. 기존 data 폴더와 food-worker.js는 유지하세요.
3. 배포 후 https://yegu1023.github.io/health/nutrition-tracker/?v=10 로 접속하세요. PC는 Ctrl+Shift+R로 새로고침하세요. 브라우저 저장 데이터는 삭제하지 마세요.

## 변경 사항
- 준비(워밍업) 체크칸을 없애고 완료 체크칸만 남겼습니다.
- 과거에 준비 세트로 저장된 데이터는 W 표시로 보존하고 본세트 집계에서 제외합니다. 새 세트는 본세트입니다.
- 휴식 시간을 60/90/120/180초 중 선택합니다. 기본 90초이며 이 기기에 선택을 보관합니다. 시간을 선택하는 것만으로 타이머가 시작하지는 않습니다.
- 중량과 횟수를 입력한 세트를 완료 체크하면 선택한 시간으로 휴식을 자동 시작합니다. 다음 세트 완료 시 타이머가 새로 시작합니다.
- 10초 남으면 짧은 알림음 두 번, 종료 시 세 번 울립니다.
- 방금 완료한 세트의 체크를 취소하면 해당 세트가 시작한 타이머와 예약된 소리를 취소합니다. 중지 버튼도 타이머와 소리를 취소합니다.
- 시작 버튼으로 수동 시작할 수도 있습니다.

## 소리 확인
운동 화면에서 알림음 테스트를 한 번 누르고 휴대폰 미디어 음량을 확인하세요. 화면 잠금·백그라운드에서는 브라우저/OS에 따라 타이머와 소리가 제한될 수 있습니다. 운동 기록 화면을 열어두고 사용하세요.

기존 운동·식단·사진 기록과 서버 동기화는 유지합니다. Supabase 추가 설정이나 유료 AI 결제가 필요 없습니다. v9의 운동 달력·통계·루틴·이전 기록 복사·코칭용 내보내기도 포함합니다.

자동 시작, 10초 전 소리 예약, 종료 소리, 중복 완료 방지, 취소 시 소리 중지, 소리 미지원 환경, 백업 호환 및 기존 식단/사진 기능 검사를 통과했습니다. 실제 휴대폰에서의 소리 재생은 알림음 테스트로 확인하세요.
